ADMIN TUTORIAL

Operate the CampPhoto AI licensing portal

This guide covers production setup, payment review, licence administration, and the frozen v1 operating rules.

Back to dashboard
Critical rule: never paste, send, email, or commit the CampPhoto AI private signing key. Customers only receive .cpa-license files.
1

Complete production configuration

In Vercel Environment Variables, confirm these are present:

DATABASE_URL PAYSTACK_SECRET_KEY CAMPPHOTO_LICENSE_PRIVATE_KEY_B64 APP_BASE_URL FLASK_SECRET_KEY ADMIN_EMAIL ADMIN_PASSWORD_HASH

The signing key must be the same key pair whose public key is bundled with the Windows application. The portal refuses to issue licences if the fingerprint does not match.

2

Configure Paystack safely

Start with a Paystack test secret key. Configure the webhook endpoint as:

{{ config["APP_BASE_URL"] }}/webhooks/paystack

Run a complete test payment before switching to a live secret. The portal verifies amount, currency, reference, activation token, Device ID, and customer email before issuing a licence.

3

Use the dashboard

The dashboard shows recent activation requests and their current state:

  • Pending: request/payment has not completed.
  • Licensed: payment was verified and a signed licence exists.
  • Revoked: server-side entitlement has been disabled.

Select Open beside a request to see customer details, payment reference, licence ID, expiry date, and audit history.

4

Use manual approval only as a fallback

Manual approval is for verified bank/payment situations where automatic Paystack confirmation cannot be used.

  1. Confirm the money in the actual company account.
  2. Open the activation request.
  3. Enter the verified payment reference.
  4. Select Manually verify & issue.
A screenshot, SMS, or customer's claim is not payment verification. The portal also prevents one payment reference from being reused for another activation.
5

Reissue a licence carefully

Reissue creates a new signed licence for the same activation record. Use it for a legitimate recovery case, not as the first response to a new computer.

If the Device ID has changed, review the case first. The licence is intentionally device-bound.

6

Understand revocation

Revoking an entitlement blocks future portal downloads and reissues.

Because CampPhoto AI is designed to work offline, a licence already imported into a disconnected computer remains valid until its signed expiry date. The portal cannot remotely erase an offline licence.
7

Use the audit trail before making decisions

The activation detail page records important actions such as payment initialization, payment verification, licence issuance, manual approval, reissue, and revocation. Review this history before correcting or overriding an entitlement.

Daily admin checklist

Confirm the portal loads and /health reports the required configuration as ready.
Review pending activations before manually intervening.
Match payment references against Paystack or the company account.
Use the audit trail before reissue or revocation.
Keep the signing key and Paystack secret only in protected server environment variables.

Frozen v1 rules

The v1 portal is frozen around one commercial flow: ₦{{ "{:,}".format(activation_fee_ngn) }} payment → verified entitlement → signed device-bound licence → offline CampPhoto AI use.

Do not alter the signing key, payment amount, licence format, verification rules, or device-binding model casually. Those changes require a coordinated release.

When something fails

  1. Check the activation's audit trail.
  2. Confirm Paystack/reference status independently.
  3. Check the Vercel health/configuration status.
  4. Check database availability.
  5. Only use manual approval after actual payment confirmation.
