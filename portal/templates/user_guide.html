USER TUTORIAL

Activate CampPhoto AI in a few steps

This guide is for camp operators and other customers activating the Windows application.

Back to activation
Before you start

Have CampPhoto AI open on the computer you want to activate. You will need its Device ID, your camp details, an email address, and access to Paystack checkout.

1

Find the Device ID

Open CampPhoto AI. On the activation screen, copy the Device ID. It looks like:

CPA-1111-2222-3333-4444

The licence is tied to this computer. Do not enter a Device ID copied from another machine.

2

Enter the camp details

Return to the portal activation page and complete:

  • Device ID
  • Camp name and state
  • Batch / Stream
  • Contact person's name
  • Email address and optional phone number

Check the Device ID carefully before continuing. A licence generated for the wrong device will not activate another computer.

3

Pay the ₦{{ "{:,}".format(activation_fee_ngn) }} activation fee

Select Pay ₦{{ "{:,}".format(activation_fee_ngn) }} securely. You will be sent to Paystack to complete payment.

Do not pay anyone who asks you to bypass the portal or send your card details directly. CampPhoto AI does not need your card number inside the application.
4

Return to the activation status page

After checkout, Paystack returns you to the portal. The portal independently verifies the transaction before issuing a licence.

If payment is still processing, use Check payment again. Repeated clicking does not create extra licences for the same activation.

5

Download the licence file

When the status becomes Licensed, select Download .cpa-license. Keep the file safe until it has been imported into CampPhoto AI.

The licence file is not your payment receipt and it is not a password. It is a digitally signed permission file for your registered device.

6

Import the licence into CampPhoto AI

Return to the Windows application, choose Import .cpa-license, select the file you downloaded, and wait for the activation-success message.

Once accepted, normal CampPhoto AI operation can continue offline until the licence expires.

What the status labels mean

created

Your activation request exists, but checkout has not completed.

payment initialized

A Paystack payment session has been created.

paid

Payment has been verified and licence issuance is completing.

licensed

Your signed licence is ready to download.

revoked

The portal entitlement has been disabled by Silabs. Contact support.

Common problems

Payment succeeded but the licence is not ready

Use Check payment again. If Paystack has confirmed the transaction but the status does not change, contact Silabs with the payment reference shown on the status page.

The licence says it belongs to another device

Confirm that the Device ID on the portal matches the Device ID shown by the CampPhoto AI installation you are trying to activate.

The computer was replaced or failed

Contact Silabs. A replacement computer has a different Device ID, so an administrator must review the existing entitlement before a replacement licence is issued.

I lost the licence file

If the portal entitlement is still valid, Silabs can help you recover or reissue the licence. Do not share the licence publicly.
